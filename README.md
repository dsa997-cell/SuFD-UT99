# SuFD — UT99 Historical Archive

Static website prepared to preserve the documented competitive history of SuFD, a Hungarian Unreal Tournament 99 player.

## Publishing
Upload the contents of this folder to a public static host (for example GitHub Pages). The page includes:
- search-friendly title/description/keywords
- JSON-LD Person structured data
- English-language canonical profile
- recovered ClanBase screenshots
- documented tournament statistics
- source/archival notes

## Important
The page does not claim that every surviving statistic came from one single ClanBase snapshot. The All Time Top 5, 2012 World Championship page, and player profile are preserved as separate historical records.
